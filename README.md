# HR Attrition Analysis

Analyzing why employees leave and which employee profiles are most at risk, using Python, SQL and Power BI.

## Dataset
IBM HR Analytics Employee Attrition & Performance dataset (Kaggle): about 1,470 employees and 35 columns covering demographics, job role, income, overtime, tenure and attrition.

## Business Questions
1. What is the overall attrition rate, and how does it vary by department and job role?
2. Does working overtime increase the chance of leaving?
3. Are lower-paid employees more likely to leave?
4. How do tenure and years since last promotion relate to attrition?
5. Which employee profile is at the highest risk of leaving?

## Tools
Python (Pandas, Matplotlib), SQL, Power BI, Git/GitHub

## Project Structure
- `data/` raw dataset
- `notebooks/` Python cleaning and analysis
- `sql/` SQL queries
- `dashboard/` Power BI file and screenshots
